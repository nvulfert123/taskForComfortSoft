Приложение для поиска N-ого минимума в *.xlsx файле.

Для начала работы необходимо склонировать проект из репозитория, выполнить команду
gradle clean build.

Запустить приложение Run 'DemoApplication. main()' через IDEA
или запустить докер контейнер в файле docker-compose.yml.

Файлы для поиска находятся в директории src/main/resources/tables.

Открываем браузер и переходим по ссылке http://localhost:8080/swagger-ui/index.html. 

Выбираем единственную ручку и вводим нужный путь до файла и число N.

После выполнения запроса получаем ответ - минимальное N-ное число в таблице.
При N= 1 будет возвращено самое минимальное число в таблице, при N = size - максимальное число.
